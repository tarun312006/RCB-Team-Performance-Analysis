RCB Team Performance Analysis (Excel Dashboard)Project Overview.
This project analyzes the Royal Challengers Bangalore (RCB) team performance using Microsoft Excel.
The analysis covers player performance, team performance, bowling comparisons (pace vs spin), and fielding efficiency, presented through Pivot Tables and interactive dashboards.
The goal of this project is to demonstrate data cleaning, aggregation, analysis, and visualization skills using Excel.

Player Analysis-
Runs scored by each player,
Strike rate comparison,
Player contribution analysis.

Team Analysis-
Role-wise contribution to team runs,
Role-wise wicket contribution,
Pace vs Spin bowling comparison,
Average economy rate analysis.

Fielding Analysis-
Total catches taken,
Total catches dropped,
Team Catch Efficiency (%).

Tools Used :
Microsoft Excel-
Pivot Tables,
Calculated Fields,
Clustered Column Charts,
KPI Cards,
Dashboard Design.
